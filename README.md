A dependency-free, touch-friendly, accessible carousel with 3D effects, free mode, virtual slides, parallax, zoom and every pagination style.

**Live examples, docs and tutorials: https://mozert-slider.vercel.app**

[Docs](https://mozert-slider.vercel.app/docs/) · [API](https://mozert-slider.vercel.app/api/) · [Examples](https://mozert-slider.vercel.app/examples/) · [Install](https://mozert-slider.vercel.app/installation/) · [Tutorials](https://mozert-slider.vercel.app/blog/) · [Changelog](https://mozert-slider.vercel.app/changelog/)

[![Mozert Slider: one slider for every layout and effect](https://mozert-slider.vercel.app/assets/og.png)](https://mozert-slider.vercel.app/examples/)

- Core + all modules: 26.4 KB gzip (core-only 12.5 KB), no dependencies, jQuery optional
- Effects: slide, fade, coverflow, cube, flip, cards, creative
- Layout: infinite loop, responsive breakpoints, fractional slides per view, gaps, center mode, variable width, rows, vertical, RTL
- Extras: free mode, mousewheel, scrollbar, parallax, zoom, virtual slides, hash navigation, marquee, video autoplay
- Galleries: thumbnails, hover magnifier, lightbox (pinch, double-tap, swipe down on touch), video gallery, bleed layout, scroll-driven sections
- Page speed: no layout jump (`--mozert-pre-ratio`), first-picture priority, native lazy loading, blur-up placeholders, autoplay pauses offscreen
- Accessible by default, respects `prefers-reduced-motion`

## Install

```bash
npm install @mozert-studio/mozert-slider
```

```js
import Mozert from '@mozert-studio/mozert-slider';
import '@mozert-studio/mozert-slider/css';
import '@mozert-studio/mozert-slider/theme.css'; // optional arrows + dots styling

new Mozert('.slider', { slidesToShow: 3, spaceBetween: 16, pagination: { type: 'dynamic' } });
```

Responsive settings use a `responsive` array with a `breakpoint` (px) and `settings` for each step. By default a `breakpoint` is a max width (the settings apply at or below it); set `mobileFirst: true` to treat it as a min width:

```js
new Mozert('.slider', {
  slidesToShow: 4,
  pagination: { type: 'dynamic' },
  responsive: [
    { breakpoint: 1024, settings: { slidesToShow: 3 } },
    { breakpoint: 640, settings: { slidesToShow: 1.4, spaceBetween: 12 } }
  ]
});
```

All options are listed in the [docs](https://mozert-slider.vercel.app/docs/#options) and the [API](https://mozert-slider.vercel.app/api/) page. Or with a script tag:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@mozert-studio/mozert-slider@1/dist/mozert.min.css">
<script src="https://cdn.jsdelivr.net/npm/@mozert-studio/mozert-slider@1/dist/mozert.min.js"></script>
```

## React and Vue

```
npm install @mozert-studio/react @mozert-studio/mozert-slider   # or @mozert-studio/vue
```

```jsx
import '@mozert-studio/mozert-slider/css';
import '@mozert-studio/mozert-slider/theme.css';
import MozertSlider from '@mozert-studio/react';

<MozertSlider slidesToShow={3} spaceBetween={16} dots thumbs lightbox>
  {products.map((p) => <div key={p.id}><img src={p.image} alt={p.name} /></div>)}
</MozertSlider>
```

Guides for Next.js, Vue 3 and Nuxt: https://mozert-slider.vercel.app/blog/#react-vue-slider. The packages live in `packages/react` and `packages/vue`.

## Develop

```bash
npm run build   # dist/
npm run site    # website into site/
npm run dev     # build + serve the website with live reload (http://localhost:5173)
npm test        # needs Playwright (Chromium) and a jQuery file, see tests/
```

`site/` is a static website (Home, Features, Examples, Docs, Installation, API, Blog, Changelog) that you can host anywhere.

Build a hero slider with parallax and a progress bar

Full-width banners that feel alive without a heavy library.

<div class="hero" data-mozert='{"parallax":true,"fade":true,"autoplay":true,"autoplaySpeed":5000,"arrows":false,"pagination":{"type":"progressbar"}}'>
  <div><img src="a.jpg" alt=""><h2 data-parallax-x="-40%">Summer sale</h2></div>
  <div><img src="b.jpg" alt=""><h2 data-parallax-x="-40%">New arrivals</h2></div>
</div>

Elements with data-parallax-x move at a different speed than the slide, which gives the depth. The progress bar follows the autoplay timer. Autoplay stops for visitors who prefer reduced motion.

Making a carousel accessible

What Mozert does for you and what is left to you.

Mozert adds the carousel role, labelled slides, keyboard arrows, focus handling and a live region that goes quiet while autoplay runs. Your part: write real alt text, keep controls visible against the images, and translate the built-in strings with the labels option.

new Mozert('.slider', {
  labels: { next: 'Suivant', prev: 'Précédent' },
  pauseOnFocus: true,
  autoplay: true
});

Build a coverflow product gallery

A centred, 3D gallery that adapts to mobile.

new Mozert('.gallery', {
  effect: 'coverflow',
  slidesToShow: 3,
  infinite: true,
  coverflowEffect: { rotate: 35, depth: 160, modifier: 1 },
  pagination: { type: 'dynamic' },
  responsive: [{ breakpoint: 640, settings: { slidesToShow: 1.6 } }]
});

Coverflow forces centerMode. Use depth for how far side slides recede and rotate for the angle. On narrow screens show fewer slides so the centre image stays large.

Render 10,000 slides without freezing the page

Virtual slides keep the DOM small.

const items = await (await fetch('/api/products')).json();
const slider = new Mozert('#catalog', {
  virtual: {
    slides: items,
    renderSlide: (p) => '<article><img data-lazy="' + p.img + '" alt=""><h3>' + p.name + '</h3></article>',
    addSlidesBefore: 3, addSlidesAfter: 4, cache: false
  },
  slidesToShow: 4, spaceBetween: 16
});

Mozert creates 10,000 empty shells (cheap) and fills the few near the viewport. Combine with data-lazy for images and with freeMode for a smooth scrolling feel.

Using Mozert in Shopify and Magento themes

Plain script tags, no build step.

In Shopify, upload mozert.min.js and mozert.min.css to assets, include them with asset_url and initialise after DOMContentLoaded. In Magento 2 with Hyvä, initialise from an Alpine x-init; with Luma, register the file in requirejs-config.js. The installation page has copy-paste snippets for both.

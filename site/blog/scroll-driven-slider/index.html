Scroll-driven slider: move slides with the page scroll

Pin a slider to the screen and let the scroll wheel move the slides sideways.

A scroll-driven slider sticks to the screen while you scroll through a tall section. Your scroll moves the slides sideways, then the page carries on. It is good for product stories, feature tours and timelines.

new Mozert('.story', {
  scrollDriven: {
    fill: true,   // the pinned slider takes the whole screen height
    offset: 76,   // px kept free at the top for a sticky header
    bottom: 24,   // px kept free at the bottom
    speed: 1.6    // px the slides travel per px of scroll
  },
  infinite: false, arrows: false, dots: false, draggable: false
});

The slider is wrapped in a tall section. The section is only as tall as the slides need to travel divided by speed, so there is no long empty scroll. Use step if you want a fixed number of pixels of scrolling per slide.

Because the page scroll drives the slides, touch and mouse wheel scrolling keep working naturally. The slider does not hijack the scroll: when the last slide is reached, the page moves on.

Bleed layout carousel: run off the screen edge

The first slide lines up with your content, the rest run past the right edge of the screen.

A bleed layout is common on shop and editorial pages: the heading and the first card sit on the page grid, but the row of cards keeps going to the edge of the browser. Mozert does this with one option.

<div class="container">
  <h2>New this week</h2>
  <div class="cards">
    <div>Card 1</div><div>Card 2</div><div>Card 3</div><div>Card 4</div>
  </div>
</div>

<script>
  new Mozert('.cards', {
    bleed: true,
    slidesToShow: 2.6,
    spaceBetween: 16,
    infinite: false,
    dots: false,
    responsive: [{ breakpoint: 640, settings: { slidesToShow: 1.4 } }]
  });
</script>

With bleed: true the first slide starts at the left edge of your container. The slider grows to the right edge of the screen, so the next card peeks out and invites a swipe. As you scroll through the row, slides leave through the left edge of the screen, and the last slide stops at the container edge instead of floating in empty space.

Tips

  • Use a fractional slidesToShow such as 2.6 so a part of the next card is always visible.
  • Keep infinite: false. A bleed row has a real start and a real end.
  • On phones use a smaller value, for example 1.4, with a breakpoint.

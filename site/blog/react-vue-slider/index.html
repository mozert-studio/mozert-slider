How to add Mozert Slider to React, Next.js and Vue

Install the official package, import the CSS, and use it as a component.

1. Install

npm install @mozert-studio/react @mozert-studio/mozert-slider

For Vue 3 use @mozert-studio/vue instead.

2. Import the styles once

import '@mozert-studio/mozert-slider/css';
import '@mozert-studio/mozert-slider/theme.css';

3. Use it

import MozertSlider from '@mozert-studio/react';

<MozertSlider slidesToShow={3} spaceBetween={16} dots lightbox thumbs>
  {products.map(p => <div key={p.id}><img src={p.image} alt={p.name} /></div>)}
</MozertSlider>

Every Mozert option works as a prop. Give each child a key; the slider rebuilds itself when slides are added, removed or reordered.

Next.js

Add 'use client' as the first line of the file that uses the component. The slider only runs in the browser, so server rendering is safe.

Vue 3 and Nuxt

<MozertSlider :slidesToShow="3" dots @change="i => current = i">
  <div v-for="p in products" :key="p.id">{{ p.name }}</div>
</MozertSlider>

In Nuxt wrap it in <ClientOnly>.

Calling methods

React: ref.current.slider.next(). Vue: ref.value.slider().goTo(2). Or keep the instance from onInit / the init event.

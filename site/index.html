What you get

Complete core

Infinite loop, responsive breakpoints, center mode, variable width, rows and grids, lazy load, synced sliders, RTL, vertical, fade, adaptive height, custom arrows and dots, and an optional jQuery adapter.

3D effects and more

Coverflow, cube, flip, cards and creative, with drag-follow, plus parallax, zoom, virtual slides, hash navigation, free mode, mousewheel and scrollbar.

Pagination your way

Bullets, dynamic bullets, fraction, progress bar and fully custom renderers.

Accessible by default

Roles, labels, keyboard, focus handling, live region while paused, and reduced-motion support.

Real touch handling

Pointer Events, axis locking, momentum, edge resistance, and no scroll-jacking on vertical swipes.

Framework friendly

Vanilla JS with ESM, CJS, UMD and TypeScript types. Works in Magento, Shopify, React, Vue and plain HTML.

Try it

npm install @mozert-studio/mozert-slider
import Mozert from '@mozert-studio/mozert-slider';
import '@mozert-studio/mozert-slider/css';

new Mozert('.slider', { slidesToShow: 3, spaceBetween: 16, pagination: { type: 'dynamic' } });

What you get

Complete core

Infinite loop, responsive breakpoints, center mode, variable width, rows and grids, lazy load, synced sliders, RTL, vertical, fade, adaptive height, custom arrows and dots, and an optional jQuery adapter.

3D effects and more

Accessible by default

Real touch handling

Framework friendly

What is Mozert Slider?

Mozert Slider is a free, dependency-free JavaScript carousel and image slider from Mozert Studio. Use it for hero banners, product galleries with thumbnails and zoom, 3D coverflow carousels, video galleries, scroll-driven sections and full-width bleed layouts. It runs in plain HTML, React, Vue, Next.js, Shopify and Magento. Learn more in the docs, the features list or the tutorials.

Try it

npm install @mozert-studio/mozert-slider
import Mozert from '@mozert-studio/mozert-slider';
import '@mozert-studio/mozert-slider/css';

new Mozert('.slider', { slidesToShow: 3, spaceBetween: 16, pagination: { type: 'dynamic' } });

Frequently asked questions

What is Mozert Slider?

Mozert Slider is a free, MIT-licensed JavaScript carousel and image slider by Mozert Studio. It has no dependencies, and it is published on npm as @mozert-studio/mozert-slider.

Is Mozert Slider free for commercial projects?

Yes. It is MIT licensed, so you can use it in personal and commercial projects.

Does Mozert Slider need jQuery?

No. It is plain JavaScript with zero dependencies. A jQuery adapter is included if you want $('.slider').mozert().

Does it work with React, Vue and Next.js?

Yes. The official @mozert-studio/react and @mozert-studio/vue packages wrap it, and it also runs in Next.js, Nuxt, Shopify and Magento themes.

Is Mozert Slider accessible?

Yes. It adds carousel roles and labels, keyboard control, focus handling, a live region while autoplay is paused, and respects prefers-reduced-motion.

How big is Mozert Slider?

About 12.4 KB gzipped for the core and 26.2 KB with every effect and module.

Features

The full list, grouped. Everything here ships in the default bundle and is switched on with options.

Layout

  • Fractional slidesToShow (2.5 slides)
  • spaceBetween gap, slideWidth, edgePadding
  • Center mode with centerPadding
  • variableWidth slides
  • Rows and slidesPerRow grids
  • Vertical and RTL
  • adaptiveHeight
  • Responsive breakpoints (max-width or mobileFirst), including "destroy"
See layouts live →

Effects

  • Slide and fade
  • Coverflow, cube, flip, cards, creative
  • Effects follow the finger while dragging
  • Per-effect option objects
  • Custom easing and CSS easing
See effects live →

Navigation

  • Arrows (custom markup, appendArrows)
  • Dots and customPaging
  • Pagination: bullets, dynamic, fraction, progress bar, custom
  • Scrollbar (draggable, auto-hide)
  • Keyboard (focused or global)
  • Hash navigation and history
  • Mousewheel
See controls live →

Interaction

  • Pointer-based drag with axis locking
  • touchRatio, dragThreshold, swipeToSlide, edgeFriction
  • Free mode with momentum and sticky snapping
  • Zoom: double-tap, pinch, pan, ctrl+wheel
  • Click to select with focusOnSelect
Try free mode →

Playback

  • Autoplay with pause on hover, focus and dots hover
  • autoplayReverse, stopOnLastSlide, disableOnInteraction
  • Events: autoplayStart, autoplayStop, autoplayTimeLeft
  • Marquee / ticker mode
  • Video autoplay with wait-for-end
See autoplay live →

Content

  • Lazy load: data-lazy, data-lazy-srcset, data-lazy-bg, progressive
  • Virtual slides for thousands of items
  • Parallax on any element
  • Fullscreen button
  • Built-in lightbox: lightbox: true
  • Thumbnail gallery from one option: thumbs: true
  • Scroll-driven slider: scrollDriven: true
  • Add, remove, filter and unfilter slides at runtime
  • Synced sliders via asNavFor (thumbnails, controllers)
See virtual slides →

Accessibility

  • ARIA roles and labels, translatable via labels
  • Roving tabindex and keyboard arrows
  • Live region toggles with autoplay
  • prefers-reduced-motion respected
  • Visible focus styles
Read the accessibility guide →

Integration

  • jQuery adapter and DOM events (mozert:afterChange)
  • ESM, CJS, UMD and TypeScript types
  • data-mozert JSON config with auto-init
  • Module API: Mozert.use() for your own effects and features
See setup options →

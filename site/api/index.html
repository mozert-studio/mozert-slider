API reference

Constructor and statics

MemberDescription
new Mozert(el, options)Create a slider. el is an element or selector. Returns the existing instance if already created.
Mozert.get(el)Instance for an element, or null.
Mozert.initAll(root?, options?)Initialise every [data-mozert] element under root.
Mozert.defaultsDefault options (mutable).
Mozert.versionVersion string.
Mozert.use(module)Register a module (see below).

Methods

MethodDescription

getOption(name) / setOption(name, value, refresh?)Read or change options live. setOption(object) also works.

Module API

Mozert.use({
  name: 'my-module',
  defaults: { myOption: false },            // merged into Mozert.defaults
  create(slider) {
    if (!slider.s.myOption) return null;    // slider.s = resolved settings
    slider._onFx((pv, animate, speed) => {  // pv = visual position in slide units
      /* update visuals */
    });
    slider._sub('afterChange', () => {});   // auto-unsubscribed on rebuild
    return { destroy() { /* cleanup */ } };
  }
});
Members starting with _ are for modules and may change between minor versions.

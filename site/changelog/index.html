Changelog

Mozert follows semantic versioning.

1.1.1 latest

2026-11-10

  • Docs and examples for prevArrow / nextArrow, appendArrows / appendDots, centerPadding and rtl.
  • Scroll-driven slider: fill: true makes the pinned slider as tall as the screen, plus speed, offset and bottom options.
  • Fixed: dots moved out of the slider with appendDots now keep their theme styling.
  • New: magnifier option. A button in the top right corner turns on hover zoom for the main picture, like a shop product page.
  • New: thumbs: { position: 'right' } puts a vertical thumbnail strip beside the main picture ('left', 'top' and 'bottom' work too).
  • New: thumbs option. One option builds a thumbnail gallery that stays in sync, instead of two sliders with asNavFor and focusOnSelect.
  • New: built-in lightbox, lightbox: true. Full-screen viewer with next/previous, zoom, swipe, keyboard and focus handling.
  • New: scrollDriven. The slider sticks to the page and your scroll moves the slides.
  • New: official @mozert-studio/react and @mozert-studio/vue packages.
  • Fixed: thumbnail strips that show every thumbnail now still highlight and select correctly; the fullscreen button label.
  • New: effect: 'expand'. The active card opens wide while the others stay narrow, smooth with drag, loop and autoplay. See the Expanding cards example.
  • New: 3D carousel look for coverflow. coverflowEffect.lift raises the cards behind the active one and fade dims them, so you get a stacked, layered carousel. See the new 3D carousel example.
  • New: step-by-step guide for adding Mozert Slider to React, Next.js and Vue.

1.1.0 first release

2026-11-10

  • Core: infinite loop, breakpoints, center mode, variable width, rows, vertical, RTL, fade, lazy loading, asNavFor + focusOnSelect, adaptive height, autoplay, accessibility, jQuery adapter, labels translations.
  • Layout options: fractional slidesToShow, spaceBetween, slideWidth, edgePadding; responsive settings: 'destroy'.
  • Dynamic slides: add(), remove(), removeAll(), filter() / unfilter(); filtered-out and removed slides leave the page completely.
  • Effects: coverflow, cube, flip, cards, creative.
  • Modules: pagination types, scrollbar, free mode, mousewheel, global keyboard, parallax, zoom, virtual slides, hash navigation, marquee, video autoplay, fullscreen.
  • Design: pagination and arrows aligned, vertical dots stay inside the slider, smoother coverflow transitions.
  • Thumbnail sliders: with asNavFor + focusOnSelect, clicking any thumbnail opens that slide and highlights it.
  • Autoplay: autoplayReverse, stopOnLastSlide, disableOnInteraction, autoplayStart / autoplayStop / autoplayTimeLeft events.
  • Module API: Mozert.use().
  • Builds: UMD, ESM, minified JS/CSS, core-only bundle, TypeScript types.

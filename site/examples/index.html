Add and remove slides at runtime

slider.add(html, index, addBefore) and slider.remove(index) rebuild the layout and keep the current slide. Try it.

Slide01Mozert Slider
Slide02Mozert Slider
Slide03Mozert Slider
Slide04Mozert Slider
Code
const slider = new Mozert('#slider', { slidesToShow: 3, infinite: false });

slider.add('<div>New slide</div>');        // append
slider.add('<div>First</div>', true);       // prepend
slider.add('<div>After #2</div>', 1);       // after index 1
slider.remove(slider.slideCount() - 1);    // remove last
slider.removeAll();                         // clear

Filtering slides

slider.filter(selector) shows only matching slides, slider.unfilter() brings everything back. A function works too.

slider.filter('.cat-a');                      // selector
slider.filter((el, i) => i % 2 === 0);         // or a function
slider.unfilter();                             // show all

Virtual slides: 2,000 slides, a handful of DOM nodes

Only the slides near the viewport hold content. Jump around with the dots or arrows.

Code
const slides = Array.from({ length: 2000 }, (_, i) => '<div>Slide ' + (i + 1) + '</div>');
new Mozert('#slider', {
  virtual: { slides, addSlidesBefore: 2, addSlidesAfter: 3 },
  slidesToShow: 3, spaceBetween: 12, infinite: false
});
